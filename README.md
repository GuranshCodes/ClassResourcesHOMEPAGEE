<h2>About</h2>
<p><b>ClassResources.ca</b> is the personal resource hub and project portal for Guransh Dhaliwal. It serves as the primary deployment environment for a growing ecosystem of educational tools, financial calculators, and software projects designed to assist with both classroom learning and independent skill building.</p>
